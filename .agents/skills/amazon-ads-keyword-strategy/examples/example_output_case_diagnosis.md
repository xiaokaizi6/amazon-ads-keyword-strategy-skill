# Example Output Case Diagnosis

Example response for Scenario D: low ACOS but natural ranking does not improve and ad order share is high.

## 1. 当前诊断

不能只看 ACOS。ACOS 10% 看起来很低，但 CPC 只有 0.2、广告单占比 70%、自然排名仍在 7 页开外，说明广告可能只是用低成本流量拿到了部分订单，并没有推动目标自然排名。当前更像 CASE001 的“低 ACOS + 高广告依赖 + 自然排名不动”模式。

## 2. 数据完整性检查

必须补充广告位、CTR、广告 CVR、整体 CVR、类目平均转化率、Session、Unit Session Percentage、TACOS、自然单占比、广告出单词列表、目标自然排名词列表。缺这些数据时，不能下“广告效果很好不用调整”的结论。

## 3. 产品阶段判断

如果是新品期，广告单占比 70% 可能是阶段性现象；如果已经进入稳定期，70% 广告单占比就是依赖风险。无论哪个阶段，当前自然排名长期在 7 页开外，都说明广告没有完成自然排名目标。

## 4. 关键词分类

| Keyword type | What to check | Decision meaning |
| --- | --- | --- |
| 出单词 | 哪些搜索词实际产生广告订单 | 判断低 ACOS 来自哪些词 |
| 排名目标词 | 想推进自然排名的大词或核心词 | 判断广告是否打在正确目标上 |
| 中小词 | CPC 低、容量小、可能容易出单 | 可贡献利润，但不一定推动大词 |
| 大词 | 高竞争、高容量、战略自然流量 | 需要独立预算、广告位、CTR/CVR 和排名复盘 |

## 5. 广告结构诊断

如果广告订单集中在中小词，而目标是大词自然排名，那么结构不匹配。应把利润型中小词和排名目标词拆开：中小词保留利润预算，目标词单独建 exact 排名组，并用广告位和自然排名复盘，而不是把全账户 ACOS 10% 当作成功。

## 6. 搜索词动作表

| Search term pattern | Action | Reason |
| --- | --- | --- |
| 低 CPC、中小词、稳定出单 | 保留但限制为利润型预算 | 能赚钱不等于能推大词自然排名 |
| 目标排名词无订单或无点击 | 检查广告位、CTR、竞价、相关性和 listing 承接 | 目标词没有有效互动就难推自然排名 |
| 高点击无单目标词 | 不直接关闭，先比较类目 CVR 和 Unit Session Percentage | 可能是 listing/价格/评论问题 |
| 无关出单词 | 不扩大预算 | 会提高广告依赖，不解决自然排名 |

## 7. 竞价和预算调整

不要因为低 ACOS 直接加预算，也不要直接关闭广告。先检查 CPC 是否过低导致只拿到低竞争流量，再看广告位是否真在目标关键词搜索页顶部、CTR 是否达标、CVR 是否接近类目平均。若目标词没有足够曝光和点击，可以小幅提高目标词竞价；若 CVR 低于类目均值，应先修转化。

## 8. 自然排名与广告关系判断

低 ACOS 不等于自然排名一定会上升。自然排名更需要目标关键词下的有效点击、转化、订单规模、整体 Session 和 Unit Session Percentage 支撑。广告出单词如果不是自然排名目标词，中小词出单通常不能直接推动大词自然排名。

## 9. 案例相似性提示

与 CASE001 高度相似：ACOS 约 10%、CPC 约 0.2、广告单占比 70%、广告位靠前，但自然排名在 7 页开外。这个案例只能作为诊断锚点，不是“低 ACOS 一定没用”的规则；它提醒要把 ACOS、CPC、广告位、CTR、CVR、Session 和自然排名一起看。

## 10. 风险和例外

广告单占比高意味着依赖风险：一旦广告预算下降，总订单可能同步下滑。例外是新品期或明确冲排名期可以暂时接受高广告单占比，但必须看到 TACOS、自然单占比或自然排名改善。评论区建议只能降置信度处理，不能直接升级为确定规则。

## 11. 7 天 / 14 天 / 30 天行动计划

7 天：导出搜索词，标记出单词和排名目标词是否一致；补广告位、CTR、广告 CVR、整体 CVR、类目平均转化率、Session、Unit Session Percentage、TACOS。

14 天：把利润型中小词和排名目标词拆成不同广告活动；目标词设独立预算和排名复盘；对无关词做否定。

30 天：如果自然排名仍在 7 页开外且广告单占比仍高，降低对中小词放量的依赖，重新评估大词目标、listing 转化、价格评论竞争力和是否需要先攻更小的阶段目标词。
